Classical harmonic systems

Classical equations of motion in lab frame

QuestBase.DifferentialEquation — Type
mutable struct DifferentialEquation

Holds differential equation(s) of motion and a set of harmonics to expand each variable. This is the primary input for HarmonicBalance.jl. After inputting the equations, the harmonics ansatz needs to be specified using add_harmonic!.

Fields

  • equations::OrderedCollections.OrderedDict{Symbolics.Num, Symbolics.Equation}: Assigns to each variable an equation of motion.

  • harmonics::OrderedCollections.OrderedDict{Symbolics.Num, OrderedCollections.OrderedSet{Symbolics.Num}}: Assigns to each variable a set of harmonics.

Example

julia> @variables t, x(t), y(t), ω0, ω, F, k;

# equivalent ways to enter the simple harmonic oscillator
julia> DifferentialEquation(d(x,t,2) + ω0^2 * x - F * cos(ω*t), x);
julia> DifferentialEquation(d(x,t,2) + ω0^2 * x ~ F * cos(ω*t), x);

# two coupled oscillators, one of them driven
julia> DifferentialEquation(
    [d(x,t,2) + ω0^2 * x - k*y, d(y,t,2) + ω0^2 * y - k*x] .~ [F * cos(ω*t), 0], [x,y]
);

QuestBase.HarmonicVariable — Type
mutable struct HarmonicVariable

Holds a variable stored under symbol describing the harmonic ω of natural_variable.

Fields

  • symbol::Symbolics.Num: Symbol of the variable in the HarmonicBalance namespace.

  • name::String: Human-readable labels of the variable, used for plotting.

  • kind::QuestBase.HarmonicKind: Role of the variable in the ansatz.

  • ω::Symbolics.Num: The harmonic being described.

  • natural_variable::Symbolics.Num: The natural variable whose harmonic is being described.

source
QuestBase.HarmonicKind — Type

Role of a HarmonicVariable in the ansatz of its natural variable.

  • CosineQuadrature: the variable u multiplying cos(ωt).
  • SineQuadrature: the variable v multiplying sin(ωt).
  • ZeroHarmonic: the constant part a.
  • LimitCycleFrequency: the limit-cycle frequency that replaces a gauge-fixed quadrature.
  • Unassigned: a bare symbol outside any harmonic ansatz.

Add the harmonic ω to the harmonic ansatz used to expand the variable var in diff_eom.

Example

define the simple harmonic oscillator and specify that x(t) oscillates with frequency ω

julia> @variables t, x(t), y(t), ω0, ω, F, k;
julia> diff_eq = DifferentialEquation(d(x,t,2) + ω0^2 * x ~ F * cos(ω*t), x);
julia> add_harmonic!(diff_eq, x, ω) # expand x using ω

System of 1 differential equations
Variables:       x(t)
Harmonic ansatz: x(t) => ω;

(ω0^2)*x(t) + Differential(t)(Differential(t)(x(t))) ~ F*cos(t*ω)

QuestBase.HarmonicEquation — Type
mutable struct HarmonicEquation{T}

Holds a set of algebraic equations governing the harmonics of a system of equations of motion. The system it was derived from is retained in source_equations and is retrievable with source; its type is the type parameter T and is retrievable with source_type.

Typically T is a DifferentialEquation, but a HarmonicEquation can also be derived from a QuantumCumulants.MeanfieldEquations.

Fields

  • equations::Vector{Symbolics.Equation}: A set of equations governing the harmonics.

  • variables::Vector{QuestBase.HarmonicVariable}: A set of variables describing the harmonics.

  • parameters::Vector{Symbolics.Num}: The parameters of the equation set.

  • jacobian::Matrix{Symbolics.Num}: The Jacobian of the harmonic equations.

  • source_equations::Any: The system of equations of motion the harmonic equations were derived from.

QuestBase.nonpolynomial_terms — Function
nonpolynomial_terms(
    x,
    vars
) -> Vector{SymbolicUtils.BasicSymbolicImpl.var"typeof(BasicSymbolicImpl)"{T} where T}

Return the subexpressions of x in which a variable of vars (or a derivative of one) appears inside an operation other than an addition, a multiplication or a power with a non-negative integer exponent. An empty result means x is a polynomial in vars.

Averaging replaces each variable by a truncated Fourier series and projects the result onto the harmonics of the ansatz. Only polynomials map a finite Fourier series onto a finite Fourier series, so terms such as sin(x), exp(x) or 1/x cannot be averaged and are returned here.

source
nonpolynomial_terms(
    diff_eom::QuestBase.DifferentialEquation
) -> Vector{SymbolicUtils.BasicSymbolicImpl.var"typeof(BasicSymbolicImpl)"{T} where T}

Return the terms of diff_eom which are not polynomial in its variables, see nonpolynomial_terms. An empty result means every equation is a polynomial in the variables and their derivatives, which averaging requires.

Trigonometrics

QuestBase.trig_reduce — Function
trig_reduce(x)

Rewrite x with every product and power of cos and sin expanded into a sum of single cos and sin terms, as in cos(a)^2 => 1/2 + cos(2a)/2. Identities such as cos(a)^2 + sin(a)^2 = 1 therefore cancel, including in denominators, which are reduced on their own first.

The rewrite is the exact spectral projection behind fourier_terms: each trig product is expanded through its exponential spectrum with numeric weights, and the arguments are written in a canonical sign. Trig arguments may be any linear combination of symbolic monomials. A trig factor that is not a positive integer power, such as 1/cos(a), is left as it stands.

Fourier projection

QuestBase.fourier_terms — Function
fourier_terms(x, t, specs)

Coefficients of f(ω*t) in x for every (ω, f) pair in specs, where each f is cos or sin. The pair (0, cos) selects the time-independent part.

x must be polynomial in cos and sin of arguments linear in t, with real coefficients and t entering nowhere else; denominators must be free of t. Phases such as cos(ωt + ψ) are allowed and produce cos(ψ) and sin(ψ) factors. Throws an ArgumentError otherwise, since such inputs have no finite Fourier series.

The coefficients are read off the exact exponential spectrum of each expanded addend, which is built once for every distinct trig product in x.

source
QuestBase.fourier_series — Function
fourier_series(x, t)

The Fourier series of x in t, as one FourierComponent per harmonic present. The time-independent part comes first, at frequency zero with a zero sine, followed by the harmonics in increasing order of their frequency vectors. Harmonics whose coefficients cancel are dropped.

x must satisfy the same conditions as for fourier_terms.

source
QuestBase.FourierComponent — Type

One harmonic of a Fourier series: cosine * cos(frequency * t) + sine * sin(frequency * t).
